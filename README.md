# 🎬 Netflix Clone - Responsive Web Application

A fully responsive, pixel-perfect Netflix UI Clone built with clean, reusable code. This project demonstrates strong fundamentals in Frontend Development, SDLC, and Git version control.

### 🚀 Features
- Fully Responsive Design (Mobile, Tablet, Desktop)
- Dynamic Movie Carousels & Hover Previews using JavaScript
- FAQ Accordion with pure JavaScript
- Clean & Reusable Code Structure (Flexbox & CSS Grid)
- Cross-browser Compatible

### 🛠️ Tech Stack 
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Concepts:** OOP in JS, DOM Manipulation, Responsive Design
- **Tools:** Git, GitHub, VS Code
- **SDLC:** Followed complete lifecycle - Planning, Design, Coding, Testing
